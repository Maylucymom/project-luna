PROJECT LUNA V2.0.1 — 매일 실사용 배포본

이 폴더 안 파일을 모두 GitHub 저장소 project-luna 최상위(root)에 올리세요.
이번 버전은 assets 폴더를 사용하지 않습니다.
이미지 파일이 index.html과 같은 위치에 있어야 합니다.

반드시 업로드할 파일
- index.html
- styles.css
- sw.js
- manifest.webmanifest
- .nojekyll
- icon-180.png / icon-192.png / icon-512.png
- 모든 png, jpg 이미지 파일

업로드 후
1. GitHub Actions의 Pages build가 초록 체크가 될 때까지 기다립니다.
2. 주소를 엽니다:
   https://maylucymom.github.io/project-luna/
3. 이전 화면이 보이면 Safari에서 새로고침하거나, 설정 > Safari > 방문 기록 및 웹사이트 데이터 지우기 대신
   먼저 주소 끝에 ?v=201 을 붙여 한 번 엽니다.
   https://maylucymom.github.io/project-luna/?v=201
4. 아이패드 Safari 공유 버튼 > 홈 화면에 추가

주의
- 기존 localStorage 기록은 같은 주소에서 계속 유지됩니다.
- Safari 웹사이트 데이터를 삭제하면 로컬 기록이 사라질 수 있으므로 설정의 JSON 백업을 주기적으로 받으세요.
