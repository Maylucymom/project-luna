PROJECT LUNA V2.4 — 메인 루틴 실행률 수정

수정 내용
- 메인 화면의 루틴 실행률이 생활루틴만 계산하던 문제를 수정했습니다.
- 이제 다음 항목을 모두 합산합니다.
  1. 학습루틴 ON 항목
  2. 부모와 함께하는 놀이 1회
  3. 아침·하교 후·저녁 생활루틴
- 각 항목을 체크할 때마다 메인 실행률이 즉시 올라갑니다.
- 꺼진(OFF) 학습·함께놀이 항목은 분모에서 제외됩니다.
- 함께놀이는 여러 선택지 중 하루 한 가지 완료를 1회로 계산합니다.
- 기존 여행일기, 날짜 자동 초기화, 함께놀이 영역 기능은 유지됩니다.
